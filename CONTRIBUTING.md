# Contributing

Thanks for helping make these examples better.

## Fixing or adding an example

1. Keep each example small and runnable: one file, or one folder with a short README.
2. Use placeholders such as `fp_your_api_key_here`, never a real key.
3. Use `https://api.fpulse.app/v1` as the base URL and send `"environment": "development"` in anything meant for testing.
4. Test it against your own free project before you open the pull request, and say in the description what you ran.

## Reporting a problem

[Open an issue](https://github.com/Fpulse-App/fpulse-examples/issues/new/choose) with the file name, the error or API response
(remove your key first) and your language or framework version.

## Security

Please do not report security problems in a public issue. Write to us through [fpulse.app/contact](https://fpulse.app/contact) instead.
