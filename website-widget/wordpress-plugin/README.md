# WordPress plugin

Adds the F-Pulse App feedback button to a WordPress site without touching the theme.

## Install

1. Download the zip: [fpulse.app/wordpress-plugin](https://fpulse.app/wordpress-plugin)
   (or zip the `fpulse-feedback-widget` folder yourself).
2. In WordPress: **Plugins > Add New Plugin > Upload Plugin**, choose the zip, then **Install Now** and **Activate**.
3. Go to **Settings > F-Pulse Feedback**, paste your widget snippet (or the `fp_...` ID) and click **Save Changes**.

Options: turn the button off, hide it from administrators, and mark a staging site as Development.

Requires WordPress 6.3+ and PHP 7.4+. Licensed GPLv2 or later. See [`readme.txt`](fpulse-feedback-widget/readme.txt)
for what the plugin sends to F-Pulse App.
